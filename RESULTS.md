# Experiment results

The two experiment directories contain the measured outputs and a short interpretation beside each plot:

- [Correctness: reference comparisons, parameter updates, and loss trajectory](results/correctness/README.md)
- [Scaling: rank and batch-size measurements, storage, and communication](results/scaling/README.md)

Run `python experiments/correctness.py && python experiments/scaling.py` from the repository root to regenerate both sets of results and their reports.
